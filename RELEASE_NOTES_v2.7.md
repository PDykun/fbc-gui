# FBC GUI v2.7 (build 51) — Release Notes

## Новые возможности

### 1. Пользовательские пресеты (настройки + CSS)
- В разделе **Настройки** появился менеджер пользовательских пресетов (`core/presets.py`).
- Сохранение, переключение и удаление именованных наборов параметров конвертации `fb2cng` и визуальных стилей CSS в папке `presets/` (`*.fbcpreset.json`).
- Экспорт и импорт пресетов для переноса конфигурации между компьютерами или обмена с другими пользователями.
- Приватные и локальные данные (SMTP-учётные данные, адреса e-mail, локальные пути сохранения и тема интерфейса) автоматически исключаются из пресетов.

### 2. Поиск, фильтр по статусам и счётчик очереди
- Над таблицей книг добавлена панель быстрого поиска (`Cmd/Ctrl+F`, сброс по `Esc`), поддерживающая многотокенный поиск без учёта регистра по имени файла, автору, серии, номеру, названию и целевому имени файла.
- Добавлен фильтр по статусу книг (**Все / Ожидают / Готовые / С ошибками**) и счётчик видимых книг (`Показано: X из Y`).
- Операция конвертации выбранных строк автоматически пропускает скрытые фильтром строки.

### 3. Отмена и повтор действий (Undo / Redo)
- Добавлен полноценный стек отмены и повтора (`QUndoStack`, `core/undo_commands.py`) с меню **Правка / Edit** (`Cmd/Ctrl+Z`, `Shift+Cmd+Z` / `Ctrl+Y`) и компактными кнопками **↩ / ↪** над таблицей.
- Поддерживаются все операции редактирования очереди: правка ячеек таблицы, диалог редактирования книги, пакетное редактирование, автонумерация серии, замена/сброс обложки, перемещение строк (`Alt+↑`/`Alt+↓`), удаление строк и очистка списка.

### 4. Визуальный конструктор заголовка книги (`metainformation.title_template`)
- В разделе **Настройки → Текст, сноски и типографика** добавлен визуальный конструктор шаблона названия книги в метаданных ридера (`metainformation.title_template`) с живым предпросмотром.
- Поддерживается запись шаблона в `config.yaml` и проверка совместимости с `fb2cng 2.1.1` через `fbc dumpconfig`.

### 5. Единый экземпляр приложения и сохранение в исходный FB2
- Реализован `SingleInstanceManager` на базе `QLocalServer` / `QLocalSocket`: повторный запуск приложения или открытие файлов из контекстного меню ОС передаёт книги в уже открытое окно и выводит его на передний план.
- Добавлена возможность сохранять отредактированные метаданные и обложку обратно в исходный `.fb2` или `.zip` (как через контекстное меню таблицы, так и галочкой в диалоге редактирования книги).

## Тестирование
- Добавлены модульные тесты для `core/presets.py`, `core/undo_commands.py`, `book_matches_filter()`, `render_title_metadata_preview()`, `save_book_changes_to_source()` и `SingleInstanceManager`.
- Все 38 модульных тестов (`./test.sh`) успешно пройдены.
