# FBC GUI v2.1 (Build 45) — Release Notes

## Русская версия (RU)

**Версия 2.1 (Ноябрь 2026) — Внешние темы QSS, дизайн Modern и переключатель День / Ночь • сборка 45**

### ✨ Новые возможности

- **Внешняя архитектура тем оформления (`themes/*.qss`)**: все стили интерфейса вынесены во внешние файлы QSS (`modern_dark.qss`, `modern_light.qss`, `golden_dark.qss`, `golden_light.qss`) для простого редактирования и добавления собственных тем.
- **Новая тема оформления Modern**: современный дизайн в двух вариантах — **Nighttime (Deep Midnight Slate)** и **Daytime (Nordic Minimalism / macOS Style)** с семантическими акцентами кнопок.
- **Объединённая тема Golden**: классические палитры `Midnight` (ночная) и `Light` (дневная) объединены в единое семейство **Golden**.
- **Быстрый переключатель День / Ночь (`☀` / `☾`)**: центральный переключатель в шапке главного окна с плавным переходом (cross-fade) и режимом **Авто** (следование системной теме ОС).

#### _Исправления ошибок и техническое обслуживание_

- _Удалена устаревшая тема `Nordic Slate`; упрощён выбор темы в разделе «Настройки → Оформление интерфейса»._

## English Version (EN)

**Version 2.1 (November 2026) — External QSS Themes, Modern Design & Day/Night Toggle • build 45**

### ✨ New Features

- **External Theme Architecture (`themes/*.qss`)**: UI stylesheets decoupled into external `.qss` files (`modern_dark.qss`, `modern_light.qss`, `golden_dark.qss`, `golden_light.qss`) for easy customization.
- **New Modern Theme**: sleek design in **Nighttime (Deep Midnight Slate)** and **Daytime (Nordic Minimalism / macOS Style)** variants with semantic action accents.
- **Unified Golden Theme**: combined classic `Midnight` (night) and `Light` (day) palettes into the **Golden** theme family.
- **Header Day / Night Switch (`☀` / `☾`)**: centered top-bar toggle with smooth cross-fade animation and **Auto** system-appearance tracking.

#### _Bug Fixes & Maintenance_

- _Removed legacy `Nordic Slate` theme and streamlined theme selection in Settings._
