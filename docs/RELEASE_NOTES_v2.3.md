# FBC GUI v2.3 (Build 47) — Release Notes

## Русская версия (RU)

**Версия 2.3 (Ноябрь 2026) — Контекстное меню списка книг, редактор метаданных и быстрый выбор формата • сборка 47**

### ✨ Новые возможности

- **Контекстное меню списка книг**: правый клик по строке книги в таблице конвертации открывает меню с действиями **«Редактировать»** и **«Удалить»**.
- **Окно редактирования книги**: отдельный диалог для редактирования автора, серии, номера и названия с живым предпросмотром имени файла, просмотром, заменой и сбросом обложки.
- **Выпадающий список форматов на главном экране**: стилизованный переключатель целевых форматов (`EPUB2`, `EPUB3`, `KEPUB`, `KEPUB3`, `AZW3`, `KFX`, `AZW8`, `PDF`, `TXT`, `MD`) на главной панели с двусторонней синхронизацией с настройками.

#### _Исправления ошибок и техническое обслуживание_

- _Быстрое удаление строк из очереди через контекстное меню._

## English Version (EN)

**Version 2.3 (November 2026) — Book Row Context Menu, Metadata Editor & Quick Format Selector • build 47**

### ✨ New Features

- **Book List Context Menu**: right-clicking any book row opens a themed menu with **Edit** and **Delete** actions.
- **Book Metadata & Cover Editor**: dedicated dialog for editing author, series, number, and title with live output filename preview and per-book cover preview, replacement, and reset.
- **Main-Screen Format Dropdown**: styled target format switcher (`EPUB2`, `EPUB3`, `KEPUB`, `KEPUB3`, `AZW3`, `KFX`, `AZW8`, `PDF`, `TXT`, `MD`) on the converter toolbar synced two-way with Settings.

#### _Bug Fixes & Maintenance_

- _Quick row removal from the queue via the context menu._
