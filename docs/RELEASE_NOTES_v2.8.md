- **Консолидированный релизный пакет v2.8**: объединяет все возможности v2.6 и v2.7 — пользовательские пресеты (`*.fbcpreset.json`), поиск и фильтры очереди, полный стек Undo/Redo, визуальный конструктор `title_template`, фоновый импорт, мгновенную отмену и интеграцию с ОС — в единой сборке для macOS и Windows.
