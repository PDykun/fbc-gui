# 📚 Руководство пользователя FBC GUI

**English version:** [User Guide (EN)](USER_GUIDE_EN.md) • **История релизов:** [docs/README.md](README.md)

**FBC GUI** — настольная студия для macOS (Apple Silicon и Intel) и Windows (x64 и ARM64) для пакетной конвертации, редактирования метаданных, визуальной настройки стилей и отправки электронных книг **FB2** и **FB2.ZIP** на базе движка `fb2cng`.

## 1. Установка и первый запуск

### Загрузка дистрибутива
Скачайте установщик для вашей системы со страницы релизов GitHub (ссылка есть в [README](../README.md)):
- **macOS (Apple Silicon M1–M4):** `FBC_GUI_v*_macos_arm64.dmg` — откройте образ и перетащите **FBC GUI** в папку **Программы (Applications)**.
- **macOS (Intel):** `FBC_GUI_v*_macos_x64.dmg`.
- **Windows (x64 / ARM64):** `FBC_GUI_Setup_v*_win_x64.exe` или `FBC_GUI_Setup_v*_win_arm64.exe` — во время установки можно включить пункт контекстного меню **«Открыть в FBC GUI»** для `.fb2` и `.zip`.

### Автоматическая настройка `fb2cng`
Сторонний конвертер `fb2cng` (`fbc` / `fbc.exe`) не включён в дистрибутив. При первом запуске FBC GUI:
1. Ищет совместимую версию `fb2cng` (`>= 2.1.1`) в системном `PATH` и стандартных каталогах.
2. Если `fb2cng` не найден, предлагает автоматически скачать официальный релиз с GitHub с проверкой контрольной суммы **SHA-256 / MD5**.

### Пользовательские файлы и настройки
В рабочем каталоге приложения (`FBC_GUI` в папке пользовательских данных ОС) хранятся `settings.json`, `config.yaml`, `ebook_styles.css`, подпапки `fonts/`, `presets/`, `themes/`, `locales/` и журнал `fbc_gui.log`.

## 2. Вкладка «Конвертер»: очередь, метаданные и обложки

### Добавление книг
- Перетащите файлы `.fb2`, архивы `.zip` (включая многокнижные) или целые папки в окно приложения.
- Нажмите **«Добавить файлы»** (`Cmd+O` / `Ctrl+O`).
- Откройте `.fb2` / `.zip` через **«Открыть с помощью FBC GUI»** (Finder на macOS или контекстное меню Проводника Windows) — файлы попадут в уже открытое окно.

Импорт выполняется в фоновом потоке с ленивой подгрузкой XML, поэтому большие библиотеки не перегружают оперативную память.

### Редактирование метаданных и жанров
- **Быстрая правка в таблице:** двойной клик по ячейке (Фамилия, Имя, Отчество, Серия, №, Название).
- **Диалог редактирования книги:** правый клик по строке → **«Редактировать»**.
  - Вкладка **«Основное»**: автор, серия, номер, название, живое превью итогового имени файла и управление обложкой.
  - Вкладка **«Дополнительно»**: визуальный редактор **жанров FB2** (интерактивные чипы, поиск по справочнику FictionBook 2.1 и поддержка пользовательских тегов вроде `litrpg`), **Язык**, **Переводчик** (дополнительные сопереводчики в файле сохраняются), **Издатель**, **ISBN** (с валидацией ISBN-10/13) и **Аннотация**.
- **Онлайн-подбор обложек и метаданных:** нажмите кнопку **«Получить онлайн»** под кнопкой **«Вернуть исходную»** на правой панели обложки (или в диалоге редактирования), либо выберите **«Подобрать обложку и метаданные онлайн...»** в контекстном меню книги. Поиск выполняется по **FantLab**, **LitRes** (оптимально для русскоязычных книг), **Open Library** (без ключа), опциональному **Google Books** (по вашему API-ключу) и универсальному **OPDS-каталогу**. В таблице **Было → Найдено** отметьте нужные поля (есть быстрые кнопки **«Только пустые»**, **«Все найденные»**, **«Только обложка»**) и выберите обложку в галерее — все изменения поддерживают Undo/Redo.
- **Пакетное редактирование:** выделите несколько книг → правый клик → **«Пакетное редактирование...»**. Можно массово изменить автора, серию, язык, а также **добавить, заменить или удалить жанры**.
- **Автонумерация серии:** выделите книги в нужном порядке → правый клик → **«Автонумерация серии»** (`1, 2, 3…`). Порядок строк легко менять через `Alt+↑` / `Alt+↓`.
- **Сохранение в исходный FB2:** отметьте галочку в диалоге редактирования или выберите **«Сохранить метаданные в исходный FB2»** в контекстном меню. Запись выполняется атомарно по принципу минимального патча в порядке XSD, не затирая нетронутую разметку.
- **Организатор исходных FB2 (без конвертации):** выделите одну или несколько книг → правый клик → **«Разложить / переименовать исходные FB2...»**. Выберите папку назначения, структуру (**Автор / Серия / Файл**, **Автор / Файл** или **Без подпапок**) и режим (**Копировать** или **Переместить**), проверьте таблицу **Было → Стало** и нажмите **«Выполнить»**.

### Отмена и повтор (Undo / Redo)
Любое изменение метаданных, онлайн-подбор, пакетная правка, замена обложки, перестановка или удаление строк поддерживают многоуровневый **Undo / Redo** (`Cmd+Z` / `Ctrl+Z`, `Shift+Cmd+Z` / `Ctrl+Y` или кнопки **↩ / ↪**).

### Поиск, фильтры, дедупликация и «Пропускать готовые»
- **Живой поиск (`Cmd+F` / `Ctrl+F`, сброс по `Esc`):** ищет по имени файла, автору, серии, названию, жанрам, языку, издателю, ISBN и целевому имени файла.
- **Фильтры статуса:** **Все / Ожидают / Готовые / С ошибками / ⚠ Проблемы**.
- **Дедупликация очереди:** книги с одинаковым автором, серией, номером и названием автоматически помечаются статусом **«≈ Дубликат»**. Кнопка **«Удалить дубликаты (N)»** убирает лишние копии одним кликом (с поддержкой Undo).
- **Пропускать готовые:** если включён этот флажок, книги с уже существующим и актуальным выходным файлом (не старше исходника и без правок метаданных/обложки) помечаются как **«↷ Пропущено»** и не конвертируются повторно.

### Обложки
Выберите книгу в таблице, чтобы увидеть обложку и её разрешение на правой панели. Кнопка **«Заменить обложку...»** автоматически подгоняет выбранное изображение под книжные пропорции `600×900 px` (LANCZOS), **«Вернуть исходную»** отменяет замену, а **«Получить онлайн»** сразу открывает окно подбора метаданных и обложки для выбранной книги.

### Запуск конвертации
- Выберите целевой формат в списке на панели инструментов (`EPUB2`, `EPUB3`, `KEPUB`, `KEPUB3`, `AZW3`, `KFX`, `AZW8`, `PDF`, `TXT`, `MD`).
- Нажмите **«Сконвертировать всё»** (`Cmd+Enter` / `Ctrl+Enter`) или **«Выбранные (N)»** (`Shift+Cmd+Enter` / `Ctrl+Shift+Enter`).
- Кнопка **«Отмена»** мгновенно завершает активные процессы `fbc`. Если часть книг завершилась с ошибкой, в окне итогов доступна кнопка **«Повторить с ошибками»**.

## 3. Инспектор структуры FB2 и отладка (`--debug`)

При импорте каждая книга проходит быструю предпроверку: при обнаружении битого XML, отсутствующей обложки, пустого названия или автора в колонке статуса появляется индикатор **`⚠ N`**.

Чтобы провести детальный разбор, нажмите правой кнопкой по книге и выберите **«Инспектор FB2...»**:
- **Сводка и проверки:** кодировка, размер XML, статус строгого разбора/восстановления, статистика разделов, абзацев, сносок и список предупреждений.
- **Оглавление (TOC):** дерево всех глав и вложенных секций.
- **Иллюстрации:** таблица встроенных `<binary>` с размерами в пикселях, весом и пометками (`обложка`, `> 2 МБ`, `Повреждено`).
- **Исправить и оптимизировать FB2:** если обнаружен битый XML, повреждённые `<binary>` или тяжёлые изображения `> 2 МБ`, кнопка внизу диалога автоматически восстанавливает валидный UTF-8 XML, удаляет пустые/битые вложения, сжимает крупные иллюстрации и атомарно сохраняет файл.
- **Сконвертировать с `--debug`:** запускает конвертацию с созданием архива `*_fbc-report.zip` рядом с выходным файлом для диагностики сложных случаев.

## 4. Вкладка «Стили»: визуальный CSS и менеджер шрифтов

Все параметры автоматически сохраняются в `ebook_styles.css` и сразу отражаются в предпросмотре:
- **1. Шрифты книги:** выбор шрифтов для основного текста, буквицы, названия книги и имени автора, а также толщина рамки страницы PDF. Пункт **«Нет»** отключает встраивание шрифтов, чтобы ридер использовал системные.
  - Справа расположена **Drop-зона для шрифтов**: перетащите туда файлы `.ttf`, `.otf`, `.woff` или `.woff2` (или нажмите на саму зону / кнопку **«Добавить шрифты...»**). FBC GUI проверит корректность заголовка файла, скопирует шрифт в `fonts/` и сразу обновит списки и превью.
- **2. Титульная страница и заголовки:** размер, цвет, выравнивание и стиль для названия, автора и заголовков `H2–H5`.
- **3. Основной текст и буквица:** выравнивание абзацев, красная строка, подзаголовки сцен, цвет и размер буквицы.
- **4. Аннотация, эпиграфы, стихи и сноски:** оформление вспомогательных блоков, фон и рамка сносок.
- **5. Иллюстрации и SVG:** выравнивание, максимальная ширина, подписи, режим **Ч/Б (Luma)**, вписывание в экран и режим масштабирования обложки.

## 5. Вкладка «Превью»: живой книжный разворот

Предпросмотр отображает либо **выбранную книгу из очереди** (левая страница — обложка во всю страницу с тенью корешка, правая — титул, аннотация, эпиграф и начало первой главы), либо **образец всех элементов стилей**.
- На macOS используется встроенный **WebKit (WKWebView)**, на Windows — **Edge WebView2**.
- Кнопка **«Открыть в браузере»** сохраняет страницу во временный `preview.html` и открывает её в системном браузере.

## 6. Вкладка «Настройки»: профили ридеров, пресеты и конструкторы шаблонов

- **Пользовательские пресеты (Настройки + CSS):** сохраняйте полные наборы конфигурации в `.fbcpreset.json`, переключайтесь между ними в один клик, сбрасывайте встроенные пресеты к эталонным или делитесь ими через **Экспорт / Импорт** (пароли SMTP и локальные пути автоматически исключаются).
- **Профили устройств:** 8 готовых профилей (**Kindle Paperwhite 2024**, **Kindle Scribe 2022/2024/2025/Colorsoft**, **Kobo Libra Colour**, **PocketBook InkPad 4**, **ONYX BOOX Go 10.3**, **reMarkable Paper Pro**) + **PDF A5**.
- **Визуальные конструкторы шаблонов:** собирайте перетаскиванием тегов (`Фамилия`, `Имя`, `Серия`, `Аббр. серии`, `№`, `Название`, `Формат`) и разделителей:
  - **Шаблон имени выходного файла** (`output_name_template`);
  - **Шаблон заголовка книги в библиотеке ридера** (`metainformation.title_template`).
- **Типографика и навигация `fb2cng`:** режим сносок (обычные / всплывающие / с перенумерацией), мягкие переносы, буквица, автотипографика прямой речи/тире/диалогов, страница аннотации и её включение в оглавление (`annotation.in_toc`), видимое оглавление (`Скрыто / В начале / В конце`), иерархия TOC (`Обычная / Старый Kindle / Плоская`), главы без заголовка, **карта страниц (`page_map`)** с режимом Adobe DE, `fix_zip` для старых читалок и масштаб иллюстраций (`scale_factor`: `0.5–2.0`).
- **Потоки конвертации:** от `Авто` до `1–8` параллельных процессов `fb2cng`.
- **Онлайн-подбор метаданных и обложек:** выбор активных источников (**FantLab**, **LitRes**, **Open Library**, **Google Books**, **OPDS**), опциональное поле для API-ключа Google Books и настройки пользовательского OPDS-каталога (URL, логин и пароль Basic Auth — секреты хранятся в системном Keychain / `keyring`).

### Подключение пользовательского OPDS-каталога (на примере Flibusta)
Универсальный OPDS-провайдер работает с любыми каталогами стандарта **OPDS (Atom XML + OpenSearch)** — как с домашними серверами (**Calibre-Web**, **Kavita**, локальный `archiveopds` на NAS по `http://` или `https://`), так и с публичными OPDS-библиотеками.

Пример подключения **Flibusta**:
1. Перейдите в **Настройки → Онлайн-подбор метаданных и обложек**.
2. Отметьте источник **OPDS** в списке **«Источники поиска»**.
3. В поле **«URL OPDS-каталога»** введите корневой адрес OPDS-каталога:
   - `https://flibusta.is/opds` (FBC GUI автоматически обнаружит шаблон поиска через OpenSearch),
   - либо напрямую шаблон поиска: `https://flibusta.site/opds/search?searchTerm={searchTerms}&searchType=books`.
4. Поля **«Логин»** и **«Пароль»** для базового поиска можно оставить пустыми (они нужны только для каталогов с Basic Auth, например личных серверов Calibre-Web / Kavita).
5. Откройте подбор кнопкой **«Получить онлайн»** на панели обложки — источник **OPDS** станет доступен наряду с остальными каталогами.

> **Примечание:** если в вашем регионе прямой доступ к домену ограничен провайдером, используйте доступное зеркало, VPN или локальный OPDS-сервер поверх собственного архива (например, `http://192.168.x.x:8083/opds`).

## 7. Доставка на ридер (USB / MTP) и отправка по e-mail (SMTP)

### Отправка по электронной почте (SMTP)
В секции **«Отправка по электронной почте»** на вкладке «Настройки»:
1. Включите **«Автоматическая отправка сконвертированных файлов»**.
2. Укажите SMTP-сервер, порт (`465` для SSL или `587` для STARTTLS), шифрование, логин, пароль приложения и адрес получателя (например, ваш адрес `@kindle.com`).
3. Нажмите **«Отправить тестовое письмо»** для проверки подключения.

Пароль сохраняется в системном хранилище (**macOS Keychain** или **Windows Credential Manager**). При массовой отправке книги автоматически разбиваются на пакеты до **20 МБ**.

### Прямая доставка на ридер (USB / MTP / sync2kindle)
В секции **«Доставка на ридер»** на вкладке «Настройки» (а также кнопкой **«На ридер»** на панели конвертера):
- **MTP (Kindle)** — для современных Kindle (Scribe, Paperwhite 12, Colorsoft) и **USB (Kindle)** — для классических моделей. При первом запуске FBC GUI автоматически скачает `sync2kindle` (`s2k`) с GitHub с проверкой контрольной суммы.
- **Папка ридера** — прямое копирование готовых книг (`.epub`, `.azw3`, `.kfx`, `.azw8`, `.pdf`, `.mobi`) в смонтированную папку Kobo / PocketBook с пропуском актуальных файлов.
- Кнопка **«Пробный запуск»** показывает список изменений без записи на устройство; опция **«Не удалять локальные книги»** защищает файлы на ПК от удаления.

## 8. Автообновления, темы и горячие клавиши

- **Автообновления:** FBC GUI проверяет новые релизы на GitHub (или вручную через **Справка → Проверить обновления...** / вкладку **«О программе»**), скачивает дистрибутив под вашу ОС и архитектуру и обязательно сверяет **SHA-256**.
- **Темы и языки:** 2 семейства тем (**Modern** и **Golden**) с режимами **Авто / Светлая / Тёмная** (переключатель `☀ / ☾` в шапке окна) и мгновенное переключение между **Русским** и **English**.

### Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Cmd+O` / `Ctrl+O` | Добавить книги (FB2 / ZIP) |
| `Cmd+F` / `Ctrl+F` | Поиск по таблице очереди (`Esc` — сбросить фильтр) |
| `Cmd+Z` / `Ctrl+Z` | Отменить последнее действие |
| `Shift+Cmd+Z` / `Ctrl+Y` | Повторить действие |
| `Alt+↑` / `Alt+↓` | Переместить выбранные строки вверх / вниз |
| `Delete` / `Backspace` | Удалить выбранные книги из очереди |
| `Cmd+Enter` / `Ctrl+Enter` | Сконвертировать все книги |
| `Shift+Cmd+Enter` / `Ctrl+Shift+Enter` | Сконвертировать только выбранные книги |

## 9. Частые вопросы и диагностика

- **Книга не конвертируется или выглядит некорректно:** откройте **Инспектор FB2...** для проверки XML/изображений и запустите **«Сконвертировать с отчётом (--debug)»** — создастся архив `*_fbc-report.zip`.
- **Где посмотреть журнал ошибок приложения:** вкладка **«О программе»** → кнопка **«Открыть лог»** (`fbc_gui.log`).
- **Как сообщить о проблеме:** откройте Issue в репозитории `PDykun/fbc-gui` на GitHub, приложив версию FBC GUI и фрагмент `fbc_gui.log`.
