# FBC GUI v2.4 (Build 48) — Release Notes

## Русская версия (RU)

**Версия 2.4 (Ноябрь 2026) — Контекстное меню списка книг, редактор метаданных и быстрый выбор формата • сборка 48**

### ✨ Новые возможности

- **Контекстное меню списка книг**: правый клик по строке книги открывает тематическое меню с действиями **«Редактировать»** и **«Удалить»**.
- **Окно редактирования книги**: отдельный диалог со всеми полями метаданных (фамилия, имя, отчество, серия, номер, название), живым предпросмотром итогового имени файла и управлением обложкой.
- **Выпадающий список форматов на главном экране**: быстрый выбор целевого формата (`EPUB2`, `EPUB3`, `KEPUB`, `KEPUB3`, `AZW3`, `KFX`, `AZW8`, `PDF`, `TXT`, `MD`) на панели конвертера с двусторонней синхронизацией с настройками.

#### _Исправления ошибок и техническое обслуживание_

- _Обновлённая сборка релиза v2.4 (сборка 48) с визуальной полировкой панели выбора формата._

## English Version (EN)

**Version 2.4 (November 2026) — Book Row Context Menu, Metadata Editor & Quick Format Selector • build 48**

### ✨ New Features

- **Book List Context Menu**: right-clicking any book row opens a themed context menu with **Edit** and **Delete** actions.
- **Book Metadata & Cover Editor**: dedicated dialog with all editable metadata fields (author, series, number, title), live output filename preview, and per-book cover preview/replacement/reset.
- **Main-Screen Format Dropdown**: styled target format switcher (`EPUB2`, `EPUB3`, `KEPUB`, `KEPUB3`, `AZW3`, `KFX`, `AZW8`, `PDF`, `TXT`, `MD`) on the converter toolbar in two-way sync with Settings.

#### _Bug Fixes & Maintenance_

- _Updated v2.4 build (build 48) with visual polish for the main toolbar format selector._
